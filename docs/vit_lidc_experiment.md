# LIDC ViT-Tiny and ViT-Small experiment (25 Oct 2026)

## Scope and interpretation

Two ImageNet-pretrained vision transformers replace the ResNet-18 *finding
predictor* on LIDC. The ten-LLM clinical edge panel is read from the existing
saved votes; **no LLM inference was rerun**. Derm7pt is not part of this
experiment. The verified CNN outputs and original report were not changed.

These are exploratory results: this held-out set had already been inspected
in earlier work. Do not use the numbers to select a model and then describe
the same test set as a fresh, confirmatory evaluation. ViTs use 10 fixed
epochs and ImageNet-21k/1k pretraining, whereas the CNN used 25 epochs and
ImageNet-1k pretraining, so this is a practical *pipeline* comparison, not an
architecture-only controlled experiment.

## Method

- Same 1,573 LIDC nodules, 3 central CT slices, HU window, 14 reader-fraction
  clinical finding targets, and audited patient-level outer split as the CNN.
- 985 fit nodules; 740 have non-indeterminate malignancy labels for fit-only
  calibration. 588 outer-test nodules; 462 have non-indeterminate labels from
  195 patients for diagnosis evaluation.
- Five patient-disjoint inner folds times five seeds produce out-of-fold fit
  predictions; five models trained on all fit nodules produce outer-test
  predictions. No test label is used for training or calibration.
- ViT-Tiny: `vit_tiny_patch16_224.augreg_in21k_ft_in1k` (Hugging Face
  revision `7d3afdd0cf93ad84d986eb2d6bcc5812ebd0b106`).
- ViT-Small: `vit_small_patch16_224.augreg_in21k_ft_in1k` (revision
  `7e2c55630205e1266030f18370f4c6ed1a514b522`).
- `timm==1.0.22`, 224×224 input, all layers fine-tuned, 10 fixed epochs,
  batch 32, AdamW, peak learning rate 1e-4. No checkpoint selection on test.
- The existing A/B1/B2 code recalibrates each model using only inner-OOF
  predictions and the fit-side labels. B2 reuses the same saved uncertain
  ten-LLM edges. The original CNN comparison is `isbi-b1-lidc-v1`.

## Held-out results

All diagnosis values use the same 462 test nodules / 195 patients. AUROC and
accuracy are proportions, not percentages. CNN values here are from the
*strict comparison run*, not the older report's 0.859 diagnosis AUROC.

| Encoder | Mean finding AUROC¹ | A AUROC / accuracy | B1 AUROC / accuracy | B2 AUROC / accuracy |
| --- | ---: | ---: | ---: | ---: |
| ResNet-18 CNN | 0.8082 | 0.8556 / 0.8095 | 0.8657 / 0.8074 | 0.7729 / 0.6580 |
| ViT-Tiny | 0.8494 | 0.8845 / 0.8420 | **0.8916 / 0.8485** | 0.8137 / 0.6580 |
| ViT-Small | **0.8564** | 0.8767 / **0.8528** | 0.8866 / 0.8463 | 0.7924 / 0.6580 |

¹ Mean over 13 evaluable findings; one finding has no valid two-class test
AUROC. See each run's `finding_auroc.csv` for individual findings.

Within ViT-Tiny, B1–A AUROC is +0.0071; the 95% patient-bootstrap interval
is [+0.0012, +0.0138]. Within ViT-Small, B1–A is +0.0099
[+0.0031, +0.0173]. B2 is substantially below B1 for both encoders.
These are exploratory intervals, not confirmatory significance claims.

Paired encoder differences (ViT minus CNN, 5,000 patient-clustered bootstrap
resamples):

| Reasoner | Tiny Δ AUROC [95% interval] | Small Δ AUROC [95% interval] |
| --- | ---: | ---: |
| A | +0.0289 [+0.0072, +0.0509] | +0.0211 [+0.0003, +0.0420] |
| B1 | +0.0259 [+0.0025, +0.0486] | +0.0209 [-0.0020, +0.0438] |
| B2 | +0.0408 [+0.0068, +0.0749] | +0.0195 [-0.0122, +0.0506] |

An interval crossing zero does not establish an encoder difference.
The exact CSV has unrounded values.

Other saved measures:

| Encoder | A errors / perception / knowledge | B1 errors / perception / knowledge | B2 errors / perception / knowledge | B1 zero-finding-hesitancy AUROC |
| --- | ---: | ---: | ---: | ---: |
| Tiny | 73 / 19 / 54 | 70 / 21 / 49 | 158 / 15 / 143 | 0.8818 |
| Small | 68 / 16 / 52 | 71 / 19 / 52 | 158 / 15 / 143 | 0.8763 |

The B2 zero-edge-width limit reproduces B1 exactly: AUROC 0.8916 for Tiny,
0.8866 for Small. The detailed attribution, calibration, edge-quality,
reader-correlation, and ablation tables are in the run directories below.

## Reproduction

Run from the repository root. Use **new** run IDs: the code intentionally
refuses to overwrite existing research outputs. The original verified
`isbi-lidc-strict-v3` split and original crop bundles must be present.
The three `/var/tmp/ifcm-lidc-crops-mimam/lidc_crops_{0,1,2}.npz` files
are also backed up under
`fresh_runs/ifs_comparison/isbi-lidc-strict-v3/cnn/source_crops_backup/`;
restore them to those exact paths if local scratch was cleared. Set `HF_HOME`
to local disk so model weights do not consume the university-workspace quota.

```bash
cd /autofs/unitytravail/travail/mimam/s_project/ifcm-expert-panel
set -e
.venv-upstream/bin/python -m pip install 'timm==1.0.22' matplotlib
export HF_HOME=/var/tmp/ifcm-vit-cache-mimam
export HF_HUB_DISABLE_XET=1

.venv-upstream/bin/python -m ifcm.safe_vit prepare --run-id my-vit-tiny --variant tiny
.venv-upstream/bin/python -m ifcm.safe_vit all --run-id my-vit-tiny
.venv-upstream/bin/python -m ifcm.safe_vit prepare --run-id my-vit-small --variant small
.venv-upstream/bin/python -m ifcm.safe_vit all --run-id my-vit-small

for pair in 'my-vit-tiny my-vit-tiny-ab' 'my-vit-small my-vit-small-ab'; do
  set -- $pair
  .venv-upstream/bin/python -m ifcm.b1 --dataset lidc --cnn-run-id "$1" --run-id "$2" --fit
  .venv-upstream/bin/python -m ifcm.b1 --dataset lidc --cnn-run-id "$1" --run-id "$2" --predict
  .venv-upstream/bin/python -m ifcm.b2 --dataset lidc --run-id "$2" --fit
  .venv-upstream/bin/python -m ifcm.b2 --dataset lidc --run-id "$2" --predict
  .venv-upstream/bin/python -m ifcm.comparison --dataset lidc --run-id "$2" --fit
  .venv-upstream/bin/python -m ifcm.comparison --dataset lidc --run-id "$2" --predict
  .venv-upstream/bin/python -m ifcm.evaluate_comparison --dataset lidc --run-id "$2" --evaluate
  .venv-upstream/bin/python -m ifcm.supplementary --dataset lidc --run-id "$2" --build
  .venv-upstream/bin/python -m ifcm.paper_outputs --dataset lidc --run-id "$2" --build
done

.venv-upstream/bin/python -m ifcm.compare_encoders \
  --tiny-source my-vit-tiny --tiny-run my-vit-tiny-ab \
  --small-source my-vit-small --small-run my-vit-small-ab \
  --output my-vit-encoder-comparison
```

The trained ViT checkpoints live in the project runs (about 0.64 GB Tiny and
2.5 GB Small); downloaded ImageNet weights live in `/var/tmp` (about 0.11 GB).
To reproduce the exact old run *without* training again, use the saved
predictions and the generated CSVs. New training can vary slightly across GPU
and PyTorch versions.

`ifcm.safe_vit all` creates the boundary proof exactly once. The separate
`ifcm.safe_vit verify` subcommand is creation-only and will raise
`FileExistsError` if run after a completed run; this does **not** mean the
boundary failed. For a repeat, read-only integrity check, use
`python -m ifcm.verify_vit_existing --run-id NAME`.

## Known limitation

The older optional `source_uncertainty.py` analysis checks a hard-coded CNN
error count (88/32) and therefore rejects the ViT runs, whose A error counts
are 73/19 and 68/16. It was not modified because its existing saved outputs
have code-hash provenance. This does not affect A/B1/B2, the standard
attribution tables, ablations, or the 44 paper-output files per ViT run.
